# 📿 Aplikasi Dzikir Pagi & Petang

Aplikasi web ringan (*Lightweight Web App*) untuk mempermudah rutinitas Dzikir Pagi, Petang, dan Sesudah Shalat Fardhu. Didesain dengan tampilan yang bersih, *mobile-friendly*, dan mudah diakses di mana saja.

🔗 **Live Demo:** [fahmimbps.github.io/dzikir](https://fahmimbps.github.io/dzikir)

---

## 📚 Sumber Rujukan

## ✨ Fitur Utama

Aplikasi ini dikembangkan dengan fokus pada kenyamanan membaca (*readability*) dan kemudahan penggunaan:

* **📖 Mode Fokus & Sticky Header:** Header tetap terlihat saat menggulir ke bawah, memudahkan navigasi.
* **📊 Reading Progress Bar:** Indikator visual untuk melihat seberapa jauh progres dzikir yang telah dibaca.
* **🌙 Antarmuka Bersih:** Menggunakan font Arab yang jelas (*Amiri*) dan layout yang nyaman di mata.
* **📱 Responsif:** Tampilan optimal di perangkat *mobile* maupun desktop.
* **🔍 Sitasi & Rujukan:** Pop-up rujukan hadits (nomor sitasi) yang interaktif tanpa mengganggu aliran membaca.
* **⚡ Ringan & Cepat:** Dibangun sebagai *Single Page Application* (SPA) sederhana tanpa *loading* berlebih.

---

## 🛠️ Teknologi

Project ini dibangun dengan pendekatan *No-Build-Step* agar mudah dipelajari dan dimodifikasi:

* **HTML5** - Struktur semantik.
* **Tailwind CSS (CDN)** - Styling modern dan responsif tanpa konfigurasi rumit.
* **Vanilla JavaScript** - Logika interaksi yang ringan (tanpa framework berat seperti React/Vue).
* **Font Awesome** - Ikon antarmuka.
* **Google Fonts** - Font *Amiri* (Arab) dan *Inter* (Latin).

## 🚀 Cara Menjalankan di Lokal

Jika Anda ingin mengembangkan atau memodifikasi kode ini di komputer Anda:

1.  **Clone repository ini:**
    ```bash
    git clone [https://github.com/fahmimbps/dzikir.git](https://github.com/fahmimbps/dzikir.git)
    ```
2.  **Buka folder project:**
    ```bash
    cd dzikir
    ```
3.  **Jalankan:**
    Cukup buka file `index.html` menggunakan browser favorit Anda (Chrome, Firefox, Safari). Atau gunakan ekstensi "Live Server" jika menggunakan VS Code.
